Solo project · Python, FastAPI, Claude API

AI Document Summarizer

A web app and API that turns a PDF, a text file or pasted text into a short executive summary of three to five bullet points.

  1. UploadA PDF, a text file or pasted text goes to the API. Files are capped at 4 MB.
  2. ExtractPyPDF2 reads each PDF page. Empty or unreadable files return a clear error.
  3. SummarizeThe first 4,000 characters go to Claude, and the bullets come back to the page.

Engineering decisions

  • Started on AWS Bedrock and S3, then moved to the Claude API. That removed two cloud services and left one secret to manage.
  • Capped upload size and the text sent to the model, which keeps cost and response time predictable.
  • Kept the API key in an environment variable so it never appears in the repository.
  • Tests replace the model call with a stub, so continuous integration runs without a key or any spend.
